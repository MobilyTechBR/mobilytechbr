## Padroes aproveitados agora

- Canvas primeiro, controles depois: o preview precisa ser o centro da acao.
- Lista compacta de elementos: evitar formulario gigante para todos os blocos.
- Inspector unico do selecionado: editar apenas o elemento selecionado.
- Acoes rapidas no elemento: duplicar, camada, centralizar, resetar.
- Edicao inline: texto editavel direto no preview.
- Context menu: clique direito para camada, opacidade, centralizacao e exclusao.
- Desktop/mobile com escala real: o preview deve preservar proporcao e permitir zoom.
- Fullscreen com gaveta de ferramentas: mais area para editar sem perder controles.
- Elementos reais importados: paginas existentes viram blocos editaveis, com marcador visual.
- Avancado recolhido: recursos completos ficam disponiveis sem poluir o fluxo principal.

## Proximos padroes recomendados

- Historico undo/redo.
- Agrupar/desagrupar blocos.
- Componentes/simbolos reutilizaveis.
- Biblioteca de secoes prontas.
- Estados hover/click por bloco.
- Guias de distancia entre elementos.
- Auto-layout simples para linhas/colunas.
- Importacao visual mais precisa por DOM real quando houver tempo para mapear cada pagina.
